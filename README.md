# Easy Code pour Windows

Easy Code t'aide à réviser le code de la route, en voiture comme en moto : séries de 40 questions, révision par thème, examen blanc chronométré et suivi de ta progression. L'appli fonctionne sans connexion.

## Télécharger

Va dans **[Releases](https://github.com/anislalou-glitch/easy-code-windows/releases/latest)** et télécharge **Easy-Code-Setup.exe**.

## Installer

1. Double-clique sur le fichier téléchargé.
2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis **Exécuter quand même**. Ce message s'affiche pour les applis qui n'ont pas encore de certificat de signature payant.
3. Suis l'installation : un raccourci **Easy Code** est créé sur le bureau.
